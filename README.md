# Customer Service Dashboard

## Tech
- HTML
- CSS
- JavaScript
- LocalStorage

## Features
- Create support tickets
- Search tickets
- Filter by status and priority
- Sort by newest/oldest/priority
- Change ticket status
- Delete tickets
- Dashboard statistics
- Persistent browser storage
- Responsive UI

## Run
Open `index.html` in a browser.

## Resume angle
Demonstrates DOM manipulation, event handling, CRUD-style UI, filtering/sorting, client-side persistence and responsive web development.
